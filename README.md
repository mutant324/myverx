# myverx — магазин винтажной одежды

Учебный проект интернет-магазина винтажных вещей (по макету из Figma):
лендинг, каталог с фильтрами, поиск, корзина, гостевые профили по кукам,
регистрация/вход и демо-оплата криптовалютой.

## стек

- **Python 3.10 + Django 4/5** — роутинг, шаблоны, CSRF, статика
- **SQLAlchemy 2.0** — база (sqlite) и все модели. Джанговский ORM не используется,
  сессия алхимии выдается в мидлвари и доступна во вьюхах как `request.db`
- **JS (ванильный) + CSS** — без бустрапа, все руками под макет:
  маркерный шрифт для заголовков, пастельная зелень, белые карточки

## как запустить

```bash
python -m venv venv
venv\Scripts\activate            # windows, в linux/mac: source venv/bin/activate
pip install -r requirements.txt

# создать таблицы и наполнить базу товарами (38 штук, 5 категорий)
python manage.py seed

# запуск
python manage.py runserver
```

сайт будет на http://127.0.0.1:8000/

пересоздать базу с нуля: `python manage.py seed --force`

## что внутри

| страница | урл | что там |
|---|---|---|
| лендинг | `/` | как в макете: hero с серым коллажем вещей и "style for day for yourself", карусели "New items in the collection" и "style for u" с точками, "haw we works" (большая фотка + история), футер с quick links. ссылки в шапке ведут на анкоры страницы |
| каталог | `/catalog/`, `/catalog/<категория>/` | сетка товаров, панель фильтров открывается кнопкой "filters". фильтры: цвет, бренд, материал, пол, размер, состояние, сезон, цена от/до, только со скидкой, сортировка |
| товар | `/product/<id>/` | фото, описание, характеристики, похожие товары |
| поиск | `/search/?q=` | иконка в шапке: первый клик — поле появилось, второй клик по пустому полю — спряталось |
| корзина | `/cart/` | изменение количества, удаление, итого |
| оформление | `/checkout/` | выбор крипты (BTC/ETH/USDT/TON), создание заказа |
| оплата | `/order/<id>/pay/` | адрес кошелька, сумма в монетах, кнопка "copy", кнопка "я отправил" |
| профиль | `/profile/` | данные юзера, его заказы. для гостя — плашка с предложением зарегистрироваться |
| регистрация | `/register/` | email, пароль, имя, фамилия, дата рождения + логин |
| вход | `/login/` | по логину и паролю |

## профили по кукам 

- каждому новому посетителю мидлварь `shop/middleware.py` создает **временный
  профиль** и запоминает его в куке `guest_token` (живет год).
  корзина работает сразу, без регистрации
- если человек регистрируется или входит — его **гостевая корзина автоматически
  переезжает** в настоящий аккаунт (`merge_carts` во вьюхах)
- после удаления кук браузером гостевой профиль потеряется — так и задумано

## важно знать (демо-режим)

- **оплата криптой — заглушка**: адреса кошельков ненастоящие, блокчейн не
  проверяется, кнопка "я отправил перевод" просто ставит статус `оплачен`.
  в реальном проекте тут нужно API ноды/платежного провайдера
- цены на сайте в долларах (как в макете), курсы крипты в `shop/models.py` тоже в $
- фото товаров — реальные, лежат в `shop/static/shop/img/products/` (p01..p16 — сток,
  new1..new5 — карусель new items) и `shop/static/shop/img/landing/` (hero, about,
  style for u, футер). чтобы заменить фото — просто закиньте файлы с теми же именами
- пароли хранятся правильно: pbkdf2 + соль (`shop/utils.py`)

## структура

```
myverx/                  настройки джанги (без auth/admin/sessions)
shop/
  database.py            движок sqlalchemy, init_db()
  models.py              модели: профили, категории, товары, корзина, заказы
  middleware.py          гостевой профиль по кукам + сессия в request.db
  views.py               все вьюхи
  urls.py                роуты
  utils.py               хеширование паролей, крипто-курсы
  management/commands/seed.py   наполнение базы
  templates/shop/        шаблоны
  static/shop/           css, js, svg-картинки
tools/make_images.py     генератор картинок товаров
```

## тесты как прогнать руками

1. открыть сайт — в шапке Balance: 0₽ (ты гость)
2. покидать вещи в корзину, порефрешить страницу — корзина на месте (кука)
3. зарегистрироваться — корзина переедет в аккаунт
4. выйти, войти по логину/паролю — корзина и заказы снова на месте
5. оформить заказ, выбрать USDT, скопировать адрес, нажать "я отправил" —
   в профиле заказ станет "оплачен"
